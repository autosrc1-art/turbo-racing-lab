# Versionado 🏁

## Regla general

Usar nombres cortos, claros y consistentes:

```text
proyecto_vX.Y.Z.W.html
```

## Incrementos

- `W`: fix menor, ajuste visual, typo, cambio chico.
- `Z`: mejora funcional.
- `Y`: bloque grande nuevo.
- `X`: versión mayor o reestructura seria.

## Ejemplo

```text
vics_q-table_v0.0.0.9.html
vics_q-table_v0.0.0.10.html
vics_q-table_v0.0.1.0.html
```
