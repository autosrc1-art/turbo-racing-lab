# Activar GitHub Pages 🏁

## Objetivo

Publicar el repo como página web.

## Pasos

1. Entrar al repo:

```text
autosrc1-art/turbo-racing-lab
```

2. Ir a:

```text
Settings > Pages
```

3. En `Build and deployment`, elegir:

```text
Source: Deploy from a branch
Branch: main
Folder: /root
```

4. Guardar.

5. Esperar a que GitHub muestre el mensaje de publicación.

## URL principal

```text
https://autosrc1-art.github.io/turbo-racing-lab/
```

## URL del Spotter

```text
https://autosrc1-art.github.io/turbo-racing-lab/apps/spotter/
```

## Nota

El archivo activo del Spotter debe vivir aquí:

```text
apps/spotter/index.html
```

Las versiones históricas pueden vivir aquí:

```text
apps/spotter/versions/
```
